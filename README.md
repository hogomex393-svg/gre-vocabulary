# GRE 词汇研习室

在线背诵网站：**https://hogomex393-svg.github.io/gre-vocabulary/**

每天 100 个全能词和 50 组等价词。全能词融合精准释义与熟词僻义；等价词按无序词对合并重复记录，保留不同释义和原书来源。

## 学习方式

- 点击显示/隐藏释义，空格键可反复切换。
- 全能词分 4×25 翻卡和中文选择检测；连连看分 30+30+30+10 词，每次正确配对保存进度。
- 等价词分 5×10 翻卡，双向找搭档练习覆盖每对的两个方向，六选二按指定词义识别。
- 错题会返回待练队列；错词连续答对两次后移出错词本。
- 固定每日额度，新词不足时补充已学词并标为复习。

## 手机和平板使用

直接在浏览器打开上面的网址，可以添加到主屏幕方便进入。

输入个人连接码或打开自己的专属同步链接后，电脑、手机和平板会自动读写同一份云存档。每次确认学习、答题和配对后自动上传；打开页面或回到页面时会读取其他设备的最新进度。连接码需要妥善保管，仅用于自己的设备。

云端只存储 AES-GCM 加密密文，连接码不会进入公开仓库。设备仍保留备份，支持手动导出/导入。尚未连接云存档时，只保存当前设备的进度。网络暂时断开时先保留设备副本，恢复网络后重试；并发更新会要求读取最新进度，防止较旧设备覆盖新进度。

本地版本仍通过 `启动网站.cmd` 运行，支持同一份云同步；当前电脑原有进度会迁移到个人云存档，原文件保留作备份。

## 文件与发布

- `dist/`：共享页面和词库，本地版本默认连接文件存档服务。
- `docs/`：GitHub Pages 发布内容，支持云同步及设备内 IndexedDB 备份，支持仓库子路径。
- `docs/books/`：来源 PDF，词条详情可以打开指定页码。
- `tools/build-pages.cjs`：把最新页面构建为 Pages 静态输出。
- `server.cjs`、`start.ps1`：本地服务和启动入口。

更新网页后执行：

```powershell
node tools/build-pages.cjs
git add dist docs tools README.md
git commit -m "Update vocabulary website"
git push origin main
```

加密云存档服务由 Sites 托管，使用独立数据库与连接码认证；GitHub Pages 负责网页。个人连接码、认证摘要和私人存档均不进入 GitHub 仓库。

GitHub Pages 发布来源：`main` 分支的 `/docs` 目录。个人存档、机器运行库、识别临时文件与日志已加入 `.gitignore`。

词库包含 2,909 个词条、1,213 个词对。六选二属于词义提示下的识别训练，真实考试仍需结合完整句子。
